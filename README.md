# 智联招聘自动投递助手 (zhaopin-auto-apply)

一个 Tampermonkey 油猴脚本，注入智联招聘网页端：

- **持续批量投递**：搜索结果页筛选好后一键开始，脚本在你眼前的真实页面上逐个跳转详情页投递（不用 iframe），状态跨页面持久化，刷新/翻页自动续跑，间隔随机 3–8 秒，不设数量上限。
- **详情页一键投递**：职位详情页右下角橙色「⚡ 一键投递」按钮。
- **简历选择记忆**：首次出现简历选择弹窗时手动选一份，脚本记住后自动使用同一份。
- **JD 关键词匹配**：可配置关键词（逗号分隔、不区分大小写），打开详情页后先匹配 JD 全文，不含关键词的岗位自动跳过；留空则不限制。
- **已投递自动跳过**：识别页面「已投递」标记 + 本地投递记录（localStorage，按岗位 ID）双重去重。
- **AI 投递提问作答**：投递流程中的表单提问由 AI 自动填写提交（未配置 AI 时跳过该岗位并记录）。
- **AI HR 聊天自动回复**：消息中心标签页打开时，轮询未读会话，AI 生成回复并自动发送（设置面板里有总开关）。
- **验证码 / 风控保护**：检测到滑块、安全验证、操作频繁时自动暂停，并弹系统通知提醒人工处理；单个岗位失败自动重试 1 次后跳过，不阻塞队列。

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展（Chrome / Edge 均可）。
2. 打开 Tampermonkey 管理面板 →「添加新脚本」→ 删除默认内容，粘贴 `zhaopin-auto-apply.user.js` 全文 → Ctrl+S 保存。
3. 确认脚本已启用，访问 https://sou.zhaopin.com 并登录智联账号。

## 配置 AI（必做，否则提问与聊天功能不生效）

1. 任意智联页面右下角点击蓝色 ⚙ 悬浮按钮（或油猴菜单「打开设置」）。
2. 填写：
   - **API 请求地址**：OpenAI 兼容地址，填到 `/v1` 或完整 `/chat/completions` 均可。兼容 OpenAI、DeepSeek、通义千问、智谱、Kimi 等。
     - DeepSeek 示例：`https://api.deepseek.com/v1`，模型 `deepseek-chat`
     - 智谱示例：`https://open.bigmodel.cn/api/paas/v4`，模型 `glm-4-flash`
   - **API Key**、**模型名**。
   - **系统提示词 / 个人背景**：控制 AI 作答口吻，建议填写个人背景让回答更贴合。
   - **JD 关键词**：例如 `LangChain, LLM, RAG`，命中任意一个才投递，留空表示全部投递。
3. 点「测试连接」确认返回正常后「保存」。
4. 首次调用某个 API 域名时，Tampermonkey 会弹窗询问是否允许跨域，选择「总是允许」。

## 使用方法

### 持续投递（无需勾选）
1. 在搜索列表页用智联的筛选条件把岗位筛好。
2. 点右下角面板的「开始投递（全部岗位）」。脚本会自动识别两种页面形态：卡片带链接时跳转到详情页投递；新版左右分栏页面（卡片无链接）则自动点击卡片，在右侧详情面板里完成投递。全程在你眼前进行，JD 匹配、简历选择、提问作答都可见。
3. 投完自动返回列表页，继续下一个岗位；页面显示已投递或本地投过的自动跳过。
4. 当前页投完后脚本会自动滚动加载 / 点击「下一页」，整页刷新后自动续跑，直到你点「停止」或连续多次没有新岗位。
5. 详情页顶部有蓝色状态条显示当前进度和结果，随时可点「停止投递」。出现验证码时脚本暂停并通知，你在页面上手动完成验证后自动继续。

### 详情页单个投递
打开岗位详情页，点右下角「⚡ 一键投递」。

### HR 聊天自动回复
保持消息中心标签页打开，脚本每 8 秒轮询未读会话并自动回复。可在设置面板用「开启 HR 聊天 AI 自动回复」开关随时暂停。

## 数据与隐私

- 所有配置（含 API Key）与投递记录仅保存在浏览器 localStorage，不上传到任何第三方。
- 已投递记录清除方法：浏览器控制台执行 `Object.keys(localStorage).filter(k=>k.startsWith('zlaa_')).forEach(k=>localStorage.removeItem(k))`。

## 自助排查

如果面板提示「没识别到岗位卡片」，按 F12 打开控制台执行：

```js
__zlaa.getJobCards().length      // 识别到的卡片数，0 说明卡片选择器失效
__zlaa.getAllJobsOnPage()        // 解析出的岗位列表，看 url/title 是否正确
__zlaa.isJobDetailUrl('某个链接') // 校验链接是否会被当作岗位详情页
```

把输出结果和当前页面 URL 发给维护者即可快速定位问题。

## 维护说明

智联前端经常改版，**所有 DOM 选择器集中在脚本开头 `SEL` 对象中**。功能失效时按 F12 打开控制台查看 `[zlaa]` 日志，优先在 `SEL` 里补充/修改选择器，无需改动逻辑代码。
